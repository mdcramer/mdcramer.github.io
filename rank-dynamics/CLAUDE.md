# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## About This Collection

The `_rank-dynamics` collection is an archive of blog posts from Surf Canyon, a search personalization startup. Posts cover product announcements, press coverage, academic research citations, tutorials, and technical essays — primarily from 2007–2011.

See the root `CLAUDE.md` for build commands, branch workflow, and site-wide architecture.

## Front Matter Convention

Every post uses this structure:

```yaml
---
title: "Post Title Here"
date: "YYYY-MM-DD"
tags:
  - "tag-one"
  - "tag-two"
---
```

Tags are always quoted strings in a YAML list. If a title contains non-ASCII characters, add an explicit `permalink` field (see root CLAUDE.md).
